## Checklist di USCITA — Fine turno

**Infermiera:** ______________________  **Data:** ____/____/______  
**Turno:** ☐ Mattina ☐ Pomeriggio ☐ Notte  **Orario:** dalle ______ alle ______

*Da compilare prima di lasciare la clinica. Nessun paziente deve restare senza consegne: se non subentra un'infermiera, le consegne vanno date al veterinario di guardia.*

### 1. Degenti
| ✓ | Attività | Note / ora |
|---|---|---|
| ☐ | Controllo finale di tutti i degenti con registrazione dei parametri | |
| ☐ | Tutte le terapie somministrate registrate in cartella (farmaco, dose, via, ora, sigla) | |
| ☐ | Terapie non eseguite o posticipate segnalate con il motivo | |
| ☐ | Fluidi sufficienti per il turno successivo; accessi venosi controllati | |
| ☐ | Box puliti, lettiere cambiate, acqua fresca | |

### 2. Documentazione e gestionale
| ✓ | Attività | Note / ora |
|---|---|---|
| ☐ | Cartelle cliniche / schede di degenza aggiornate su Snoots | |

| ☐ | Consensi informati firmati e archiviati | |
| ☐ | Campioni di laboratorio etichettati, registrati e inviati / conservati correttamente | |
| ☐ | Registro consegne compilato per ogni paziente | |

### 3. Passaggio consegne
| ✓ | Attività | Note / ora |
